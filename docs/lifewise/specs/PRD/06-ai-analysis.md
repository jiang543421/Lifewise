## 1. 产品目标（SMART）

| 维度 | 描述 |
|---|---|
| **Specific** | 为用户提供「跨模块数据洞察 + 单模块深度报告 + 自然语言问答」三大 AI 能力 |
| **Measurable** | 单模块报告首 token P95 < 3s；端到端 < 30s；问答规则路径 P95 < 500ms |
| **Achievable** | 本地 Ollama + deepseek:8b 模型；ContextBuilder 纯 SQL；Job Queue 异步化 |
| **Relevant** | AI 是产品差异化核心；其他 5 个模块的数据汇聚点 |
| **Time-bound** | MVP（Phase 1）交付单模块报告 + 智能问答（规则优先）；跨模块洞察放入 Phase 2 |

**核心 OKR**：
- **O1**：让用户「从数据中获得洞察，而不只是记录」
- **KR1.1**：注册用户 14 天内触发至少 1 次 AI 报告的比例 ≥ 40%
- **KR1.2**：AI 报告采纳率（生成后未被删除的比例）≥ 70%
- **KR1.3**：AI 问答满意度（用户对回答点赞的比例）≥ 60%

## 2. 用户画像

### 用户画像 A：数据反思者「于博士」

- **角色**：30-45 岁高学历 / 知识工作者
- **痛点**：记了很多数据但从未分析过；想要月度复盘但自己写太累
- **核心任务**：
  1. 每月初生成上月消费 / 任务 / 饮食综合报告
  2. 看报告时点击「为什么」让 AI 解释数据异常
  3. 收藏有价值的洞察

### 用户画像 B：忙碌懒人「Lulu」

- **角色**：22-30 岁职场新人
- **痛点**：不愿意看原始数据，但想知道「我最近怎么样」
- **核心任务**：
  1. 在 AI 报告页直接看 AI 总结
  2. 偶尔问一两个问题（不需要深度）
  3. 看到 Push「本周有趣发现」会点进去

### 用户画像 C：自学者「老王」

- **角色**：35-55 岁持续学习者
- **痛点**：想对比不同时期的自己（半年前 vs 现在）；想找规律
- **核心任务**：
  1. 输入「对比 3 月和 6 月的任务完成情况」让 AI 生成对比报告
  2. 看到 AI 找出「4 月到 5 月任务下降是因为饮食不规律」
  3. 收藏对比报告

## 4. KANO + RICE 划分逻辑

### KANO 模型归类

| 需求 | KANO 类别 | 理由 |
|---|---|---|
| 单模块报告（纯 JSON） | **基本型（MUST）** | AI 模块的存在基础 |
| 自然语言问答 | **期望型（SHOULD）** | 显著差异化，但用户可手动查统计也能用 |
| LLM 解读 / 流式输出 | **期望型（SHOULD）** | 体验增益明显 |
| 跨模块洞察 / 推送 | **魅力型（COULD）** | 用了惊喜，但单模块报告也能给基础洞察 |
| 多轮对话 / 操作 | **无差异型（WON'T）** | 复杂度高，MVP 不涉及 |

### RICE 评分

| 需求 | Reach | Impact | Confidence | Effort | RICE | 决策 |
|---|---|---|---|---|---|---|
| 单模块报告（纯 JSON） | 0.9 | 3 | 1.0 | 2 | 1.35 | **进 MVP**（SQL 聚合 + UI） |
| LLM 解读（可选） | 0.7 | 3 | 0.7 | 3 | 0.49 | **进 MVP**（差异化关键） |
| 规则引擎快速问答 | 0.8 | 2 | 0.9 | 1 | 1.44 | **进 MVP**（零成本省 LLM 调用） |
| LLM 生成 SQL 问答 | 0.5 | 3 | 0.5 | 5 | 0.15 | **进 MVP**（慢路径） |
| Ollama 健康检查 | 1.0 | 2 | 1.0 | 0.3 | 6.67 | **进 MVP**（基础设施） |
| 跨模块洞察 | 0.6 | 3 | 0.5 | 6 | 0.15 | **v1.1**（依赖稳定数据） |
| 报告订阅 | 0.4 | 2 | 0.7 | 4 | 0.14 | **v1.1** |
| 多轮对话 | 0.3 | 2 | 0.5 | 8 | 0.038 | **v1.2** |

**结论**：MVP 收纳单模块报告 + 问答（规则 + LLM 双路径） + 健康检查；跨模块洞察与订阅明确 v1.1。

## 5. 用户故事

### US-AI-01：月度消费报告自动生成

> 作为**数据反思者于博士**，我需要**每月初一键生成上月消费报告**，以便于**不用自己手动整理 Excel**。

**验收标准（AC）**：
- **AC-1**：AI 模块首页选「消费 / 上月」点击「生成报告」立即返回 jobId
- **AC-2**：报告页 5 秒内显示「已生成」状态，结构化 JSON 立即可见（饼图、Top5、月度对比）
- **AC-3**：LLM 解读部分流式输出，首 token < 3s，端到端 < 30s；不可用时按钮降级为「纯数据视图」

### US-AI-02：LLM 解读更易理解

> 作为**忙碌懒人 Lulu**，我需要**AI 用人话解读数据**，以便于**不用自己看图表**。

**验收标准（AC）**：
- **AC-1**：报告页开启「AI 解读」开关后，下方出现「🤖 解读」区域，流式打字机效果
- **AC-2**：解读包含 3 部分：本月核心数据（2 句话）+ 异常点（最多 3 条）+ 建议（最多 2 条）
- **AC-3**：用户可对解读点赞 / 点踩，反馈写入数据库用于后续优化

### US-AI-03：自然语言提问

> 作为**自学者老王**，我需要**直接问「3 月任务完成率是多少」**，以便于**不用自己去筛选数据**。

**验收标准（AC）**：
- **AC-1**：AI 模块首页底部固定输入框，输入问题后 1 秒内规则引擎先尝试
- **AC-2**：规则匹配时直接返回答案（500ms 内），不调 LLM
- **AC-3**：未匹配时进入 LLM 通道，回答流式输出，结尾提供「数据来源」按钮可看 SQL

### US-AI-04：AI 健康度透明

> 作为**用户所有人**，我需要**看到 AI 服务是否正常**，以便于**不调 LLM 时知道是降级状态**。

**验收标准（AC）**：
- **AC-1**：AI 模块首页右上角展示角标：绿（healthy）/ 黄（slow > 5s）/ 红（unavailable）
- **AC-2**：点击角标展开详情：队列堆积、平均延迟、失败率
- **AC-3**：红色状态下「生成 AI 解读」按钮 disabled 并 tooltip「AI 服务暂不可用」

### US-AI-05：报告历史回看

> 作为**数据反思者于博士**，我需要**能看到过去生成的报告列表**，以便于**对比月度变化**。

**验收标准（AC）**：
- **AC-1**：报告历史 Tab 展示过往生成的所有报告（按时间倒序），含模块、周期、生成时间
- **AC-2**：点击历史报告直接打开当时的报告视图（JSON + 解读快照）
- **AC-3**：支持按模块 / 时间范围筛选历史报告

## 6. 功能范围与边界

### In Scope（MVP）

- 单模块报告生成（任务 / 日报 / 消费 / 饮食 / 计划）
- 时间段选择：本周 / 本月 / 上月 / 最近 30 天 / 自定义
- 报告纯 JSON 视图（图表）+ 可选 LLM 解读（流式）
- 自然语言问答（规则快速路径 + LLM 生成 SQL）
- SQL 安全校验（白名单表 + 只读 + LIMIT）
- 30 天对话历史
- AI 健康度角标
- Ollama 客户端抽象 + 健康检查

### Out of Scope（明确不做）

- **不做**：跨模块洞察推送（v1.1）
- **不做**：报告订阅 / 自动生成（v1.1）
- **不做**：多轮对话（>10 轮）（v1.2）
- **不做**：问答 + 操作（「删除数据」）（v1.2）
- **不做**：趋势预测（v1.2）
- **不做**：外部 LLM 接入（仅本地 Ollama）

## 8. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
|---|---|---|---|
| **LLM 偶发胡言 / 输出有毒内容** | 高 | 中 | Prompt 强约束 + 输出正则校验；显示「AI 生成内容仅供参考」水印 |
| **LLM 生成 SQL 存在注入风险** | 高 | 低 | 白名单表 + 只允许 SELECT + AST 解析拒绝任何非查询操作 |
| **Ollama 服务挂掉导致 AI 全模块不可用** | 高 | 中 | 健康检查 + 降级为纯 JSON 视图；Job Queue 自动重试 3 次 |
| **LLM 推理慢（30s+）影响体验** | 中 | 中 | 首 token < 3s 硬指标；超过 30s 自动 cancel 并降级 |
| **跨模块洞察的「假关联」（把巧合当因果）** | 中 | 高 | 解读文案强约束用「相关」不用「导致」；每条洞察附「证据」链接到原始数据 |
| **用户隐私顾虑（数据送 LLM）** | 中 | 中 | 仅本地 Ollama；产品页明确「数据不出本机」；用户可一键关闭 AI 解读 |
| **API 速率限制不够严格被滥用** | 中 | 低 | 每用户 10 req/min + 60 req/h + 全局 100 req/min；异常用户自动熔断 |
